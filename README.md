# Krishi Saathi — multilingual farmer chatbot

A natural-farming helpline chatbot for Indian farmers. It runs as a **website chat widget** and as an **Android/iPhone app**, both on one backend and database.

**Features:**
- **22 Indian languages plus English.** Auto-detects the language and also understands romanised text like "jeevamrutham eppadi?".
- **Voice questions** in 22 languages, and **read-aloud** answers.
- **Crop photo diagnosis.**
- **Answers grounded in your own knowledge base.** The bot won't invent dates, numbers or contacts.
- **Saved chat history** and an optional **farm profile** for tailored advice.
- **Suggested follow-up questions** and 👍/👎 feedback.
- **Admin page** for editing the knowledge base, with insights on languages, topics and knowledge gaps.

**Stack:** Node.js + Express backend · Claude API (Sonnet 5.5 / Haiku 5.5) · Supabase PostgreSQL · Sarvam AI (voice) · Expo React Native app · plain-JS embeddable widget.
